# PreU Perú AI

Aplicación educativa para postulantes
a las universidades del Perú.

## Universidades

- UNDAC
- UNEVHAL
- UNMSM
- UNI
- UNFV

## Funciones

- Banco de preguntas.
- Importación desde Excel.
- Simulacros de admisión.
- Administración desde celular y computadora.
- Actualización de preguntas por Internet.
